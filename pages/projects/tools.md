# More tools
[go back](projects)

[LenixSO github](https://github.com/LenixSO)

- [custom button](https://github.com/NoTaskStudios/com.notask.custom-button)
an more customizable version of unity's button, allowing multiple types of transition, and state change callbacks.

- [number utilities](https://github.com/LenixSO/NumberUtilities)
some static methods for checking/modifying numbers that i oftem find useful.

- [sequences](https://github.com/LenixSO/Sequences)
a simple but useful interface/classes to manage the execution of many different asyncronous processes and/or animations.

## Work in Progress

- [color palette](https://github.com/LenixSO/Color-palette)
a tool to easily check and change the colors across your unity project.

- *physics movement*
a system to make it easier to make physics based movement on unity.
there's no public repository for it yet, but is what i used for this [demo](https://lnkd.in/p/eeeafZKr).

- *grid manager*
a sytem for managing grids, UI or otherwise.
it is still in the early stages so for now i don't have anything public about it.
